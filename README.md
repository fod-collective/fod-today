# FOD Today

Freedom On-Demand daily command board (dark / gold). Today-only — no week or month views.

## Live

Published via GitHub Pages from `main` (root).

## Local

Open `index.html` or serve the folder:

```bash
python3 -m http.server 8787
```

## Rebuild

The Daily Growth Pulse regenerates `index.html` + `today.json` each morning (~7:49 AM CT) and pushes to this repo so Pages stays current.
